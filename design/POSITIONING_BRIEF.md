# CMAT Positioning, Specialization, and Professional Presentation

CMAT should be specialized hard around a clear research niche instead of being presented as generic media-analysis software.

## Recommended positioning

**Primary positioning:**

> Scientific content analysis software for children’s television and video research.

**Alternative broader positioning:**

> A research toolkit for sampling, coding, validating, and analyzing children’s media.

This should make the product feel like specialized scientific infrastructure, not a vague AI tool.

## Core brand ideas

### 1) Children’s media first
The product should immediately signal that it is designed for researchers studying children’s media. Do not present it as generic software that happens to support that domain.

### 2) Scientific workflow, not AI magic
The interface should emphasize methodological transparency and reproducibility.

A central idea for the product is:

> Sampling → Selection → Measurement → Validation → Results

The pipeline visualizer should embody that workflow and make it feel like the methodology itself is the interface.

### 3) Built for researchers, not programmers
The product should feel approachable to undergraduates and research assistants while still being credible for serious researchers.

A good positioning line is:

> Rigorous enough for publication. Accessible enough for an undergraduate research assistant.

## Suggested website / documentation structure

Use pages that map to real researcher tasks:

- `/sampling` — Sampling Television Episodes for Content Analysis
- `/human-coding` — Human Coding for Children’s Media Research
- `/validation` — Validating Automated Media Analysis Against Human Coders
- `/interrater-reliability` — Reliability and agreement workflows
- `/automated-analysis` — What the software can measure
- `/research-workflows` — End-to-end examples
- `/docs` — Practical documentation

Each page should teach something useful and give search engines enough context to understand the product.

## Tone and visual identity

Avoid startup-y language like:

- “supercharge your media research with AI”
- “next-gen intelligence platform”
- “revolutionize your workflow”

Use a tone that feels academic, careful, and trustworthy.

Better phrases:

- Design reproducible children’s media studies.
- Construct samples, manage corpora, perform human and automated measurement, validate computational measures, and export research-ready datasets.
- From sampling frame to results.

## Product language to use

Use research-native terms that users will recognize:

- method
- sample
- unit of analysis
- coding scheme
- measure
- reliability
- validation set
- corpus
- provenance
- export
- reproducibility

Expose these progressively so beginners are not overwhelmed.

## High-value features that make the software look serious

- A persistent pipeline visualizer that shows the full workflow clearly.
- Rich node metadata in an inspector panel.
- Clear sampling provenance and reproducibility details.
- A “cite this method” or auto-generated methods-summary feature.
- Separate support for human coding and automated analysis.
- Strong validation and reliability tooling.

## Canonical use cases

The product should support a set of recognizable research workflows:

- Developmental psychology research on children’s media exposure
- Educational media comparison across programs or networks
- Content analysis for children’s television producers or researchers
- Communication / media studies projects on representation, violence, prosocial behavior, language, or advertising
- Computational behavioral science that validates automated measures against human coding

## README / homepage recommendation

The top of the README should say something like:

> Children’s Media Analysis Toolkit (CMAT)
>
> Open-source research software for reproducible content analysis of children’s television and video.
>
> CMAT helps researchers move from a population of media to an analysis-ready dataset through an explicit research pipeline:
>
> Sampling → Selection → Measurement → Validation → Results

Then show one strong screenshot of the pipeline interface and explain the main features in plain research language.

## Important product principle

CMAT is not a general-purpose AI video analyzer. It is scientific workflow software for researchers conducting reproducible quantitative and computational content analysis of children’s media. Every major product decision should reinforce methodological transparency, research validity, and ease of use.
