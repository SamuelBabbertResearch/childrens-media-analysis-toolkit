# CMAT — Repository map

Where things are, and what to edit for a given kind of change. Update this file
whenever files move, a folder changes purpose, or a system is added.

---

## Top-level folders

| Folder | Purpose |
|---|---|
| `analyzer/` | The engine and data model. **Imports no GUI framework** — enforced by `tests/test_engine_isolation.py` |
| `ui/` | The Qt (PySide6) front-end. The current interface |
| `tests/` | pytest suite |
| `validation/` | Hand coding, codebooks, and trial manifests — **authoritative data a person typed** |
| `docs/` | Long-form documentation; `docs/wiki` |
| `Shows/` | The episode library for this working copy (`<root>` in the docs) |
| `pipelines/` | Fallback pipeline documents — **gitignored, personal project data** |
| `_site/` | The **Open Children's Media Index** — the published dataset site, generated by `build_site.py` |
| `build/`, `dist/` | PyInstaller output — never edited by hand |

## What to edit, by kind of change

| I want to… | Edit |
|---|---|
| change how a metric is computed | the relevant `analyzer/metrics_*.py`, then `analyzer/measurements.py` |
| add a metric | `analyzer/schema.py`, its `metrics_*` module, `analyzer/measurements.py`, `ui/report.py`, `ui/settings.py` labels |
| change what a screen looks like | `ui/theme.py` (tokens in `ui/tokens.py`) — read `ui/DESIGN.md` §0 first |
| add or change a pipeline stage type | `NODE_TYPES` in `analyzer/pipeline_graph.py` — a dict entry, not a UI change |
| change how pipeline status is derived | `analyzer/pipeline.py` |
| change scoring (weights, ceilings) | `config.json` presets; the dialog is `ui/settings.py` |
| change the analysis report | `ui/report.py` — no Qt import, testable headless |
| add a command-line entry point | `cli.py` — never duplicate engine logic in a front-end |

## Engine — `analyzer/`

| Module | Role |
|---|---|
| `engine.py` | per-episode analysis; dispatches to the selected tool per measurement |
| `batch.py` | whole-show runs with a progress callback |
| `measurements.py` | registry: which tool produces each measurement, with what parameters, and whether it is validated. Fingerprints settings so stale cache is detectable |
| `metrics_cuts.py` | shot boundaries, dissolves, cut classification |
| `metrics_frames.py` | colour, motion, flashing (shared frame pass) |
| `metrics_audio.py` | RMS loudness, dynamic range (via FFmpeg) |
| `speech.py`, `vocab_complexity.py` | WPM and speech density; readability, tiers, AoA, MTLD |
| `metrics_sensory.py` | the weighted composite |
| `aggregate.py` | show-level statistics (`ShowAggregate`) |
| `cache.py`, `db.py` | disk cache and SQLite index; staleness detection |
| `show_index.py` | folder discovery (one level of category nesting) |
| `schema.py` | `EpisodeResult`, `ShowAggregate`, `MetricStats` |
| `sampler.py`, `trials.py` | reproducible episode sampling; the run registry |
| `validation.py`, `event_coding.py` | tool-vs-human scoring, Cohen's kappa, inter-coder agreement |
| `pipeline.py` | **derived** workflow status from what is on disk |
| `pipeline_graph.py` | **editable** pipeline documents, node types, templates |
| `provenance.py` | self-reported accuracy figures |
| `prefs.py` | per-user local state, kept out of the versioned config |
| `config_loader.py` | loads and normalises `config.json` |
| `optional_tools.py`, `detector_transnet.py` | optional dependency registry; TransNetV2 wrapper |
| `report_pdf.py` | PDF export |
| `wiki_importer.py`, `tvmaze_importer.py` | episode metadata import |
| `intro_templates.py` | reusable coding-sheet templates |
| `ffmpeg_path.py` | locates the FFmpeg binary |

## Interface — `ui/`

| File | Role |
|---|---|
| **`DESIGN.md`** | **the visual specification — §0 is the recipe for building a screen; read before porting anything** |
| `reference/*.css` | the supplied design mockups' stylesheets, extracted verbatim. **The source of the design, not a copy of it** |
| `reference_css.py` | loads those, resolves `var()`, returns a component's rules |
| `tokens.py` | design tokens; **no framework imports** — shared by both front-ends |
| `theme.py` | fonts, the Qt stylesheet |
| `main_window.py` | the shell: title bar, toolbar, tabs, Library, and the pipeline tab's actions |
| `modal.py` | `WindowTitleBar`, the dialog frame, `ConfirmDialog` |
| `native_frame.py` | suppresses the Win32 frame's *drawing* while keeping snap, resize and the system menu |
| `pipeline_view.py` | the node canvas: nodes, wires, pan, zoom |
| `inspector.py` | the pipeline inspector panel |
| `report.py` | analysis results as HTML; **no Qt import**, so it is testable headless and reusable for PDF export and the static site |
| `automated.py` | the Automated coding tab and its worker thread |
| `index_tab.py` | the Index tab over the SQLite index |
| `handcoding.py`, `player.py` | the Human coding tab; VLC embedded in Qt |
| `trials_tab.py` | the Trials registry |
| `settings.py` | Presets & Weights — **scoring settings only** |
| `welcome.py` | the starting-layout wizard |
| `chart.py` | per-episode component chart (matplotlib) |

## Entry points

```
python -m pytest -q                    the test suite — run before and after any change


python cmat_qt.py                      the Qt build — the current application
python gui.py                          the Tk build — legacy, being retired

python cli.py analyze <file.mp4>       single episode → JSON
python cli.py analyze <show_folder>    batch → per-episode JSON + aggregate
python cli.py db episodes <root>       list indexed episodes
python cli.py db shows <root>          list indexed shows

python validate_cuts.py …              template / export / compare / sweep / summary
python code_events.py …                template / rates / agreement / publish
python build_site.py                   static site
```

What each script is for:

| Script | Role |
|---|---|
| `cmat_qt.py` / `gui.py` | application entry points (Qt / Tk) |
| `cli.py` | headless analysis and index queries |
| `build_site.py` | builds the **Open Children's Media Index** from the corpus |
| `validate_cuts.py` | transition validation against hand coding |
| `code_events.py` | fantastical-event coding: rates, agreement, publish |
| `sample_youtube.py` | YouTube sampling list by upload-date spread — **list only, no downloads** |
| `patch_speech_cache.py` | one-off maintenance for cached speech results |
| `preview_ui.py` | scratch UI preview — untracked, see `TODO.md` |

## Legacy Tk front-end

`gui.py` plus 14 `gui_*.py` modules. Complete, and still the only home of the
**Episode Sampler** and Human coding's **Validate tool** / **Agreement**
screens. Delete a module only when its screen has reached parity in `ui/`.
